# 门禁卡与刷卡处

本目录保存门禁卡浮窗和房卡门刷卡提示的裁剪图，供[刷卡处](../../container.md#刷卡处)的判定和以后的门禁卡模板制作参考。

## 来源

全部取自同一段用户录屏：城郊幻境高危，从「风蚀公路_高」出生，刷开「风蚀公路汽车旅馆二层」。录屏为 1920×1080，本身是有损视频编码，所以这些裁剪图虽然按无损 WebP 保存，也不能作为像素级模板裁剪源；做模板时要用游戏内截图重取。录屏不入库，帧时间写在下表，按 4 帧每秒抽帧，误差约 ±0.25 秒。

## 文件

刷卡提示的裁剪矩形都是 `(1260, 430, 1650, 760)`，覆盖 `交互F键` 与 `交互图标` 两个区域。浮窗的裁剪矩形都是 `(590, 210, 1010, 470)`，取自仓库页点击门禁卡后弹出的浮窗。

## 已知限制

- 录屏只拍到这三张卡和另外两种卡（六昏街录像店一楼的蓝色 D 卡、绮梦沙滩某馆西门的蓝色 A 卡），不能证明每个房间的卡图标都不同。芝邦邦餐厅和仓储中心板房两张卡只差字母 A 与 B。
- 「切换」提示说明可能可以用滚轮切换选中条目，尚未实测；当前实现遇到拾取物挡住时点按 F 把它捡走。

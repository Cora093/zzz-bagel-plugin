源录像标识为 `Zenless Zone Zero 2026.10.24 - 00.41.12.04.DVR.mp4`，尺寸 3840×2160，标称 60 FPS，总长约 36.281 秒。编码为 H.264、YUV 4:2:0，颜色标记为 BT.709。原录像未纳入仓库；以下帧可独立复核，不依赖外部文件路径。

## 适用限制

- 附件仅包含四格容量的局内满箱画面；两格、三格和小容量仓库没有本目录的真实样本。
- 录像只覆盖一段已有游戏操作。它证明画面顺序与外观，不证明当前自动化发送的输入被游戏接受。
- 挂锁与时钟对照支持区分这两种图案，不证明全部光照、动画和物品外观均已覆盖。
- 哪些物品会失活、确认后每种物品的去向，以及修改后自动化的完整结算流程，仍需分别核对。
